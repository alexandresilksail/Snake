# 贪吃蛇 3D · 无限闯关 + 单机竞技（Snake 3D / Snake V2.0）

基于原生 2D 贪吃蛇升级的高品质 3D 网页游戏：真正的 Three.js 3D 场景（立体蛇身、3D 食物、动态光照、阴影、镜面反射、程序化天空与七元素光球），无限关卡逐关递增难度，现代化「原神」风格 UI；并内置**单机 Slither.io 竞技模式**：连续移动、鼠标转向、10 条本地 AI 蛇、能量球、实时排行榜。

## 特性

- **真 3D 画面**：Three.js r160 WebGL 渲染；立体蛇头（吻部/大眼/分叉舌）、圆球蛇身（每吃一豆 +1 段，尾端金辉增长特效）、3D 食物、动态光照、阴影、反射地板、程序化青空天空与雾效。
- **无限关卡**：主线 10 关 + 无限模式；地图逐关变大（18×14 → 36×28）、方块逐关放大（1.0× → 2.0×）、速度/障碍/移动路障/迷宫/寒冰与黄金食物轮换递增。
- **单机竞技模式（V2.0）**：主菜单「竞技模式 · 10 蛇乱斗」入口；连续移动 + 鼠标/触屏转向；空格/鼠标左键加速（消耗长度）；10 条本地 AI 蛇（目标选择/寻路/避碰/吃食增长/死亡掉落能量球/重生）；圆形开放式竞技场 + 边界判定；普通/黄金/寒冰食物 + 死亡能量球；实时排行榜（前 6）、长度/分数 HUD、暂停/继续/重开/返回菜单、竞技结束面板（最终长度/分数/排名）。
- **完整体验**：开始/暂停/继续/重开/通关/游戏结束，分数、最高纪录、关卡显示，金币与皮肤商店。
- **操作**：经典模式 方向键 / WASD / Enter / Esc(P) / R；竞技模式 鼠标移动转向 + 空格或鼠标左键加速；手机触屏滑动 + 虚拟方向键。
- **音乐音效**：程序化 BGM 与吃食/黄金/寒冰/死亡音效，静音记忆（M 键）。
- **兼容性**：Chrome / Edge（含软渲染 SwiftShader）；WebGL 不可用时自动降级 2D Canvas 模式，竞技模式同样可用。
- **本地优先**：单 HTML 文件 + 本地 three.min.js，离线可用，无外部依赖。

## 运行方法

1. 将 `snake_game_3d.html` 与 `three.min.js` 放在同一目录；
2. 双击 `snake_game_3d.html`（或拖入 Chrome / Edge 浏览器）即可开始游戏。

> 也可以直接部署到任意静态托管（GitHub Pages / Vercel / 本地服务器），无需构建。

## 测试

回归测试使用 Playwright（Chromium）：

```bash
python3 snake_test.py      # 经典模式 3D + 2D 共 59 项
python3 arena_test.py      # 竞技模式 A–H 共 33 项 + 经典冒烟 2 项
```

测试项包括：启动无错误屏、3D 初始化、菜单/选关/开始、键盘与触屏方向、吃食加分与身体增长、黄金食物 +3、通关/解锁/金币、撞墙与撞身死亡、重开、暂停/继续、无限关卡生成与难度递增、皮肤商店、音乐解锁/静音持久化、WebGL 禁用时的 2D 兼容模式全功能；竞技模式覆盖：吃食只触发一次且 3D 身体同步增长、100 步跟随、连吃 20 一致、AI 增长与死亡掉落、碰撞死亡与重开重置、食物生成合法性（无空位不无限循环）、10 分钟稳定性（37500 帧无异常、单帧 < 4ms、内存增长 < 80MB）。
